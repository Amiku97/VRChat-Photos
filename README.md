# VRChat Photos - Club Dawn&Dusk 🎭

Repozytorium do przechowywania i wyświetlania zdjęć z VRChat w Puppet Live Poster!

## 📁 Struktura

```
VRChat-Photos/
├── images/           # Tutaj umieszczaj swoje zdjęcia
│   ├── photo1.png
│   ├── photo2.jpg
│   └── ...
└── README.md        # Ten plik
```

## 🖼️ Jak uploadować zdjęcia?

1. Wejdź do folderu `images/`
2. Kliknij **"Add file"** → **"Upload files"**
3. Wybierz swoje zdjęcia (PNG, JPG, itp.)
4. Kliknij **"Commit changes"**

## 📸 Formaty obsługiwane

- PNG
- JPG/JPEG
- GIF
- WebP

## 🎯 Jak użyć z Puppet Live Poster?

W Puppet Live Poster użyj ścieżki:
```
https://raw.githubusercontent.com/Amiku97/VRChat-Photos/main/images/nazwa_zdjecia.jpg
```

**Przykład:**
```
https://raw.githubusercontent.com/Amiku97/VRChat-Photos/main/images/photo1.png
```

## 📝 Notatki

- Upewnij się że zdjęcia są w dobrej jakości
- Nazwy plików nie powinny zawierać polskich znaków (użyj `_` zamiast spacji)
- Maksymalny rozmiar pliku: 25 MB
